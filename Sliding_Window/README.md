# 🪟 滑动窗口 (Sliding Window)

## 💡 个人见解

滑动窗口本质上是**双指针的一种变体（同向双指针）**。通过维护一个由左右指针 `left` 和 `right` 组成的“窗口”，右指针不断向右扩张以寻找可行解，左指针在满足条件时向右收缩以优化解。它极大地避免了重复计算，是把**多层嵌套循环（暴力破解 O(n²)）优化为 O(n) 线性时间**的利器。

## 🎯 适用题型

- 连续子数组或子串问题（如最长无重复子串、最小覆盖子串）。
- 求解满足特定条件的连续子序列的长度、最大和、最小和。
- 定长窗口问题（如找到字符串中所有字母异位词）。
- 遇到“连续”、“子数组”、“子串”等关键词，且暴力解法需要双层循环时，优先考虑滑动窗口。

## ⚠️ 使用注意与优化窍门

1. **明确窗口内维护的数据**：例如元素的和、字符频率、不同字符的个数等。
2. **右指针扩张逻辑**：`right` 向右移动，将新元素纳入窗口并更新状态，通常用 `for` 循环。
3. **左指针收缩逻辑**：判断窗口内状态不满足条件时，通过 `while` 循环移动 `left`，并**及时移除移出窗口元素的影响**。
4. **定长与不定长**：
    - 定长窗口（如固定长度的子串）：通常用 `if` 判断，而不是 `while` 收缩。
    - 不定长窗口（如最短/最长子串）：需要用 `while` 循环将 `left` 收缩到满足条件为止。
5. **结果更新时机**：
    - 求最长窗口：通常在窗口扩大并满足条件后更新（在 `while` 收缩前）。
    - 求最短窗口：通常在窗口收缩并满足条件时更新（在 `while` 收缩中）。
6. **边界问题**：确保 `left` 不超过 `right`，避免索引越界。

## 🕳️ 踩过的坑与错题本

- **坑1：收缩时忘记更新状态**。在移动 `left` 指针时，**必须**把移出窗口的元素从状态中剔除（如减去计数、从哈希表中减1），否则后续判断必错。
- **坑2：`while` 循环条件写反**。导致窗口无法正常收缩或提前结束，引发死循环或漏解。
- **坑3：哈希表更新逻辑混乱**。字符异位词类题目，`right` 进窗口时加计数，`left` 出窗口时减计数，计数为 0 时应及时删除键，避免干扰比较。
- **坑4：定长窗口与不定长窗口混淆**。定长窗口用 `if` 且 `right` 走到终点即停，不定长窗口用 `while` 且 `right` 不一定走到终点。

## 🧩 滑动窗口通用模板

### 模板一：不定长窗口（求最长/最大满足条件的子串）

**适用场景**：求满足条件的最长连续子数组/子串（如「无重复字符的最长子串」）。

```python
left = 0
res = 0
for right in range(n):
    # 1. 扩张：把 nums[right] 纳入窗口，更新状态
    # 2. 收缩：当窗口不满足条件时，移出 nums[left]，left 右移
    while 不满足条件:
        移除 nums[left]
        left += 1
    # 3. 更新答案：此时窗口一定满足条件
    res = max(res, right - left + 1)
```

**核心要点**：
- **先扩张，后收缩，最后更新答案**。
- 求最长时，答案在 `while` 收缩**之后**更新。
- `while` 的条件是「窗口**不**满足要求」。

---

### 模板二：不定长窗口（求最短/最小满足条件的子串）

**适用场景**：求满足条件的最短连续子数组/子串（如「长度最小的子数组」）。

```python
left = 0
res = float('inf')
for right in range(n):
    # 1. 扩张：把 nums[right] 纳入窗口，更新状态
    # 2. 收缩：当窗口满足条件时，先更新答案，再移出 nums[left]，left 右移
    while 满足条件:
        res = min(res, right - left + 1)
        移除 nums[left]
        left += 1
```

**核心要点**：
- **先扩张，满足条件后收缩，收缩时更新答案**。
- 求最短时，答案在 `while` 收缩**之中**更新。
- `while` 的条件是「窗口**满足**要求」。

---

### 模板三：定长窗口（元素判重版）

**适用场景**：判断窗口内是否有重复元素（如「存在重复元素 II」）。

```python
window = set()
for right in range(n):
    # 1. 进：右侧元素加入窗口
    if nums[right] in window:
        return True
    window.add(nums[right])
    # 2. 出：窗口超过 k 时，左侧元素移出
    if len(window) > k:
        window.remove(nums[right - k])
return False
```

**核心要点**：
- 用 `for` 循环，窗口大小固定为 `k`。
- 每次移动：**右侧进一个，左侧出一个**。
- 用 `if` 判断（不是 `while`），因为窗口大小固定，只需要移动一次。

### 模板四：定长窗口（频率统计版）

**适用场景**：统计窗口内元素频率，做频率比对（如「找到字符串中所有字母异位词」「字符串的排列」）。

```python
# 1. 初始化第一个窗口（下标 0 到 k-1）
window = {}
for i in range(k):
    window[s[i]] = window.get(s[i], 0) + 1
# 此时判断第一个窗口是否满足条件

# 2. 滑动窗口：每次右移一格，左出右进
for right in range(k, len(s)):
    # 进：右侧新元素加入
    window[s[right]] = window.get(s[right], 0) + 1
    # 出：左侧旧元素移出
    left_char = s[right - k]
    window[left_char] -= 1
    if window[left_char] == 0:
        del window[left_char]
    # 此时判断当前窗口是否满足条件
```

**核心要点**：

- 用 `dict`（哈希表）维护频率。
- 窗口大小**恰好为 k**。
- 每次移动：**右侧进一个，左侧出一个**。
- 计数为 0 的键要及时删除，避免干扰后续比较。



---

### 📊 三种模板对比

| 模板   | 窗口类型         | 收缩方式             | 更新答案时机   |
| :----- | :--------------- | :------------------- | :------------- |
| 模板一 | 不定长（求最长） | `while` 不满足时收缩 | 收缩后更新     |
| 模板二 | 不定长（求最短） | `while` 满足时收缩   | 收缩中更新     |
| 模板三 | 定长             | `if` 每次移动一次    | 每次移动后判断 |
