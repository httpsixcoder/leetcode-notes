# 🧠 LeetCode 算法刷题笔记 (Algorithm Notes)

👋 欢迎来到我的算法学习仓库！

这是一个持续更新的算法刷题记录仓库。作为一名刚步入职场的新人，我在这里记录自己学习数据结构和算法的心路历程、解题思路以及踩过的坑。

## 📌 初衷与目的
- 建立自己的算法知识体系，拒绝“为了刷题而刷题”。
- 记录每一次踩坑、优化和灵光一闪，方便日后复盘与面试复习。
- 把这里当作一块磨刀石，养成持续输出和总结的习惯。

## 📂 目录结构
目前按算法类型进行划分，每个二级目录都包含该类型的：
- 📖 `README.md`（核心思路、适用题型、模板代码、高频踩坑与错题本）
- 📝 对应题目的 `.py` 文件（包含题目描述、代码实现、时间/空间复杂度分析）
